# Preview 19 성능 검증

도구 목록·카드 상태를 메모리에 캐시한다. 표시용 캐시는 사용자 데이터의 manager-display-cache.json에만 기록하며, 설치 상태의 신뢰 근거로 사용하지 않는다. 시작 시 캐시를 먼저 표시하지만 로컬 재검증이 끝날 때까지 버튼 변경과 관리 메뉴를 비활성화한다. 실제 변경은 기존 Core 서비스의 해시·소유권·백업·세션 검증을 계속 사용한다. Core와 Reload bridge 소스는 이번 변경에서 수정하지 않았다.

저장소 조회는 도구 등록의 계정 저장소 새로 고침 등 명시적인 요청에 한정한다. 로컬 새로 고침은 네트워크를 호출하지 않는다. 조회 실패 시 마지막 목록을 보존한다. 등록된 저장소 정보는 로컬 파일에서 읽는다. 다운로드·설치는 사용자 요청 시 기존 인증과 검증을 사용한다.

시작 시 설치 확인·압축 해제·목록 구성은 작업 스레드에서 수행한다. 메뉴 이동·검색·주기적 버튼 갱신은 해시를 다시 계산하지 않는다. 상태 파일 메타데이터 또는 호스트 PID 변경을 감지하면 스냅샷을 갱신한다. 갱신 중에도 메뉴 전환과 검색은 가능하다.

실제 사용자 설치(41개 명령)에서 1차 측정: 캐시 목록 표시 144ms, 백그라운드 확인까지 2,508ms. pyRevit 카드 35개 첫 생성은 1,082ms, 재방문은 117ms. 반복 전환과 변경 없는 상태 확인의 추가 목록 스캔 0회, 저장소 조회 0회. 첫 진입의 WinForms 카드 생성 비용은 남아 있다. 이 값은 해당 PC에서 폼이 표시된 이후 측정한 값이며 실행 파일 초기 로딩 전체 시간을 뜻하지 않는다.

UI 검사 172개와 임시 설치·재설치·제거 10개 통과. 최종 설치본 성능은 작업공간 artifacts/manager-preview19-performance-installed.json에서 확인한다. 모델이나 도구 설치 선택, 리본 배치는 변경하지 않는다.
최종 설치본 측정: 캐시 표시 85ms, 배경 확인 완료 2,509ms, pyRevit 35개 카드 첫 진입 889ms, 재방문 96ms. 변경 없는 반복 확인의 목록 스캔과 GitHub 조회는 0회였다. 확인 중 UI 타이머 41회 작동 및 표시 캐시 직렬화/재읽기를 확인했다. 실제 설치 EXE의 SHA-256은 검증 빌드와 일치한다.
