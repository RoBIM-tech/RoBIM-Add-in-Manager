# 카드 목록 Manager · Preview 9

사용자가 확인한 카드 목록 시안을 Windows Forms Manager에 적용했습니다. 오른쪽 업데이트 안내는 표시하지 않습니다. 첫 제품 화면은 기존 지침대로 Revit이며 전체 도구와 내 도구 메뉴를 추가했습니다.

## 동작

- 전체 도구: 두 제품의 등록 도구. 내 도구: 관리 설치 또는 기존 설치 연결 상태의 도구.
- Revit: 독립 native 패키지와 pyRevit 패키지를 함께 표시하되 유형을 구분. AutoCAD: CAD 패키지.
- 이름/설명/제품/유형을 대소문자 구분 없이 검색. 기본 순서는 독립 Revit 모듈 우선, 이름순과 설치 우선 정렬 제공.
- 카드의 기본 작업은 기존 InstallFlow의 현재 상태/실행 중 호스트/인증/Reload 준비 결과에 따라 결정.
- `···`에서 상세 정보, 설치 폴더, GitHub 저장소, 복원, 제거. 기본 Revit 도구에는 사용자 프로필/Reload 준비, CAD 모듈에는 동봉 버전/최신 기능/ZIP 준비 메뉴.
- 로컬 수정, 관리 설치 여부, 외부 설치 여부에 따른 기존 허용 조건 유지. 준비 작업은 실행 중인 CAD/Revit에 직접 변경을 적용하지 않음.
- 작업 중 전체 제품 화면과 기본 버튼을 잠그며 완료 후 상태를 갱신.
