# Manager 1.1.1 정식 승격 · 2026-10-30

사용자 요청으로 Manager 1.1.1-test.2, Revit Host 1.0.1-test.1, CAD Loader 1.1.1-test.1의 검증된 구현을 정식으로 승격한다. 순서는 Revit Host 1.0.1 / CAD Loader 1.1.1 → Manager 동봉 잠금 갱신 → Manager 1.1.1이다. 개별 기능 및 공용 라이브러리 채널은 변경하지 않는다. 기존 TEST와 정식 Release는 유지한다.

Manager는 여러 실행 창 적용, 리본 편집 관리 아이콘, 도구 설명 정리를 포함한다. 소스 기능 구현과 공유 프로토콜은 TEST와 동일하게 유지하며 버전/패키지/배포 문서만 갱신한다. 기존 ID·선택·사용자 리본 이름과 위치는 보존한다. 기능 의미의 독립 뷰도 보존한다.

검증자는 Codex 자동 검사다. TEST 실제 PC 증거는 Workspace의 MULTI_SESSION_20261030.md 및 MANAGEMENT_ICONS_AND_WORDING_DELIVERY_20261030.md를 참조한다. Revit 2026.5+ / AutoCAD 2026.1.2+와 .NET 10 환경의 두 실제 GUI 프로세스 각각에서 Host applied 응답을 확인한 구현을 승격한다. validation.by/hostBuild/evidence와 정식 빌드·설치 결과는 최종 전달 기록에 별도로 기록한다. 이를 기능 알고리즘의 새 실모델 검증으로 해석하지 않는다.

Manager 자체 업데이트는 열린 호스트를 종료하지 않아도 된다. 고정 Host/Loader 설치 교체는 해당 프로그램 전체 종료 후 수행한다. 종료 전 실제 DLL을 교체하거나 설치 채널을 재표시하지 않는다. 정식 Release 게시와 실제 PC 연결 설치 완료는 구분한다.
