# Revit 세션 복구·도구 목록 스크롤 · 2026-11-09

Manager 1.1.6-test.1은 Revit 도구 화면과 리본 편집에 ‘현재 Revit에 다시 준비’를 제공한다. 저장한 선택/패키지 해시를 검증하고 현재 실행 창의 PID·시작 시각을 새 요청 ID에 기록한다. 원격 패키지를 내려받거나 다른 캐시 버전으로 바꾸지 않는다. 게시 직전 실행 세션과 기존 요청 ID를 재확인한다. 새 요청에 대한 실행 창별 applied 회신 전에는 대기로 표시한다. 리본 적용 요청도 함께 보내며 결과는 호스트 응답으로 판별한다.

도구 카드 배치 완료 후 UI 메시지 큐에서 레이아웃과 세로 콘텐츠 범위를 갱신한다. 이전 스크롤 위치는 새 범위 안으로 제한해 복원한다. 카드 갱신과 창 너비 변경 모두 같은 경로를 사용한다.

검증 화면은 임시 카드 1개→40개 증가, 중간 스크롤 위치에서 재배치, 넓은 창→좁은 창의 세 조건을 사용한다. 각 조건에서 스크롤바, 마지막 버튼의 뷰포트 내 위치 및 Click 이벤트를 검사한다. 실제 사용자 도구를 설치하거나 삭제하는 검사가 아니다. 세션 검사는 새 ID/선택 보존/다중 창 일부 회신/전체 회신을 구분한다. 실제 Revit 세션 복구와 사용자 모델 명령 실행 검증은 별도다. Host·CAD Loader·공유 프로토콜은 수정하지 않는다.

검증 결과: 정상 Windows 사용자 환경 엔진 298/298 및 스크립트 회귀 통과(ExitCode 0). 최초 샌드박스 실행은 서로 다른 기존 파일 복구/접근 검사에서 실패했으나 정상 환경 재실행은 모두 통과했다. 최종 TEST 카드 UI 274개 통과, 세 스크롤 조건의 마지막 버튼 위치·Click 이벤트 및 PNG 캡처 확인. 실제 Revit 복구 회신 검증과 실제 사용자 목록 새로고침은 아직 미수행.
