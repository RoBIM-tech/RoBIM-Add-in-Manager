# Preview 16 — 미설치 Revit 버튼 표시 수정

사용자가 설치하지 않았는데 Revit 리본에 모든 버튼이 나타나는 문제를 확인했다. 기존 설치 정리 때 운영 버튼 35개를 선택 설치로 자동 이관한 상태와, pyRevit 환경에서 layout 메타데이터만으로 미선택/TEST 버튼을 숨기지 못한 문제가 함께 있었다.

- 사용자 요청에 따라 Revit 운영 버튼과 독립 시트 기능의 선택 상태를 0개로 초기화한다. CAD 선택은 유지한다.
- 선택하지 않은 명령 bundle 전체는 프로필 루트의 `.robim-disabled` 아래 같은 상대 경로에 보관한다. 실제 `.tab`/`.panel` 탐색 트리에서는 빠지므로 YAML 해석과 관계없이 로드되지 않는다. 공용 라이브러리와 원본은 보존한다.
- 다음 선택 변경 시 보관 bundle을 먼저 복원한 후 새 선택을 다시 구성한다. 비활성 목록의 경로·형식·중복을 검증하고 관리 설치 해시 보호를 유지한다.
- 카탈로그는 미설치 버튼을 계속 제공하고, 아이콘도 보관 경로에서 읽을 수 있다. 전체 도구/호스트 목록은 설치 가능한 기능, 내 도구와 실제 리본은 선택된 기능을 나타낸다.
- 바이너리 경로 변경은 기존 Reload 검증을 우회하지 않는다. 해당 버튼에 재시작이 필요한 DLL/EXE/CS 변경이 있으면 실행 중 적용은 거부한다.

검증: 엔진 116/116, 설치 패키지 10개 검사 통과. 빈 선택의 활성 명령 폴더가 비어 있고 보관된 버튼을 다시 설치할 수 있는지 확인했다. 최종 실제 Revit 및 설치본 상태는 작업공간 artifacts/manager-preview16-update-result.json에 기록한다.

리본 편집과 버튼별 버전 선택은 아직 구현하지 않았다. 이 버전에 존재한다고 안내하지 않는다.
