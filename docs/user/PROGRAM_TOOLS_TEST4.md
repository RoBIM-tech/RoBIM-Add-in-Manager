# 프로그램별 도구 · TEST 4

Revit·AutoCAD 화면에서 도구를 검색하고 상태(설치됨/업데이트/미설치)와 정식/TEST를 골라 확인합니다. 별도 전체 도구·내 도구·TEST 도구 메뉴는 없습니다.

정식 설치는 녹색, TEST 설치는 파랑, 정식 업데이트는 주황, TEST 업데이트는 보라, 미설치는 회색입니다. 현재 버전과 제공 버전을 함께 확인합니다. 새 TEST가 있어도 정식이 자동 교체되지 않습니다. TEST 보기를 누르고 TEST 설치를 선택하면 현재 버튼을 교체하며 배치는 유지합니다. 이전 정식은 카드의 관리 메뉴에서 선택합니다.

리본 편집 왼쪽에는 아직 배치하지 않은 버튼만 나옵니다. 배치를 삭제하면 다시 왼쪽에 나타납니다. 배치 삭제는 도구 제거가 아닙니다. 제작자/조직은 도구 등록에서, 로더는 프로그램 로더에서 관리합니다.

로더의 옛 설치 ID는 관리 기록을 읽을 때 연결됩니다. 기존 파일이 수정됐거나 구·신 기록이 충돌하면 자동 교체하지 않습니다. CAD 로더 업데이트에는 AutoCAD 종료가 필요합니다.
