# Manager 1.1.6 정식 승격 · 2026-11-11

사용자 요청에 따라 1.1.6-test.1(e9ab3c3)의 기능 코드를 유지하고 Manager 1.1.6 정식으로 승격한다. Revit 도구/리본 편집의 현재 세션 다시 준비, 새 요청 ID와 PID·시작 시각별 적용 회신 확인, 카드 배치 후 스크롤 범위 갱신과 위치 복원을 포함한다. Host 1.0.2 / CAD Loader 1.1.2 / Access Core 0.1.1과 호환되며 고정 로더 교체는 필요하지 않다.

기준 TEST 검증: 정상 Windows 사용자 환경 엔진 298/298 및 스크립트 회귀 통과. 최종 TEST 화면 검사 274개 통과. 임시 카드 1→40개 증가·중간 위치 재배치·창 너비 축소의 세 조건에서 스크롤바, 마지막 버튼의 뷰포트 내 위치와 Click 이벤트를 검증했다. 실제 사용자 목록 새로고침과 실제 Revit 복구 회신/사용자 모델 명령 실행은 아직 미검증이다. 정식 승격이 이 미수행 검증을 대체하지 않는다. 정식 파일 빌드·게시·SHA-256 검증과 실제 PC 설치는 별도 단계로 구분한다.
