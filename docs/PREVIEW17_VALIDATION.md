# Preview 17 — Revit 리본 편집

왼쪽 `리본 편집`에서 탭·패널을 만들고 버튼 목록 또는 트리에서 드래그하여 배치한다. 표시 이름과 큰/작은 버튼을 선택할 수 있다. 위/아래 이동은 키보드 Ctrl+↑/↓로도 가능하다. 기본 배치, 저장, 새로 읽기, Revit에 적용, 결과 확인을 제공한다.

편집은 설치와 분리된다. 미설치 버튼은 회색으로 표시되며 배치를 저장해도 설치하지 않는다. 실제 리본에는 설치된 버튼만 배치하고, 빈 탭·패널을 표시하지 않는다. 설치 기능이 0개면 관리 연결 탭도 표시하지 않는다. Manager의 Revit Reload에서 첫 설치 준비를 적용할 수 있다.

Manager 소유 pyRevit 연결의 startup/Idling을 사용하며 pyRevit 본체는 수정하지 않는다. JSON 요청은 단일 Revit PID·시작 시각을 확인한다. 모델 수정 중에는 적용을 보류한다. 모델을 저장하거나 Transaction을 실행하지 않는다. 다른 제품 탭에 같은 이름으로 배치하려는 경우 거부한다. 버튼의 기존 명령 연결과 소스 경로를 유지하고 실행 중 UI 항목의 위치·표시 크기만 변경한다. 삭제가 제한된 Revit 리본 객체는 빈 화면에서 숨기며, 재시작 후에도 저장한 배치가 적용된다.

사용자 지적에 따라 제거는 파일 보관과 구분했다. 미설치 명령 bundle은 실제 설치 폴더에서 삭제한다. 재설치용 전체 원본은 설치 경로 밖의 `.robim-button-source-*` 캐시에 저장하고, 확인 정보와 파일별 해시를 검증한다. 이전 `.robim-disabled` 보관 방식은 전환 시 제거한다. 변경된 설치 사본/바이너리/캐시는 자동으로 덮어쓰거나 무시하지 않는다.

범위: 이번 리본 편집 화면은 Revit용이다. AutoCAD의 기존 버튼 이름·패널·순서 구성은 기존 메뉴에서 유지한다. 버튼별 버전 선택은 아직 별도 작업이다.

검증: 엔진 123개, WinForms UI 166개 검사 통과. 설치 패키지의 임시 설치·재설치·제거 10개 검사 통과. 실제 Revit의 적용 결과, 최종 설치 선택과 표시 탭은 작업공간 artifacts/manager-preview17-update-result.json에 기록한다.

최종 실행 확인(2026-10-20): 독립 시트 Add-in의 camelCase 활성 상태를 읽도록 연결을 보완하고 Revit 2026.5 Home PID 57416에서 작은 버튼의 사용자 탭·패널 배치를 확인했다. 같은 세션에서 Native Reload로 버튼을 제거한 뒤 설치 선택 0개와 표시 RoBIM 탭 0개를 확인했다. 모델은 열거나 수정하지 않았다.

Reload 잠금 회귀 보완: 설치 루트와 동일 DLL을 유지하고 해시가 달라진 허용 파일만 원자 교체/제거한다. 전체 백업을 남기며 실패한 변경은 원본으로 복구한다. 잠긴 루트·동일 DLL, 실제 명령 폴더 제거, 바이너리 변경 차단, 부분 실패 복구 검사 4개를 추가했고 엔진 123/123과 UI 166/166, 설치 10개 검사를 통과했다. 최종 Revit PID 59764에서 추가 Reload 적용을 확인했다.

최종 정리: PID 59764에서 pyRevit 추가 및 제거 Reload가 연속 성공했다. 최종 Native/pyRevit 선택 0개, 버튼 파일과 비활성 보관 폴더 없음, 표시 RoBIM 탭 0개, 원래 없던 배치 설정 복원. 사용자 모델은 열거나 수정하지 않았다.
