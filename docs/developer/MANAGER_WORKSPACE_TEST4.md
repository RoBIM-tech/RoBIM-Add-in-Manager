# Manager 프로그램별 도구 및 CAD 로더 식별자 전환 · TEST 4

새 로더 설치 ID는 robim-cad-loader이다. delhidden은 레이어 정리 모듈·명령에 사용하며, 과거 로더 기록을 읽는 호환 처리와 이력에는 남는다. 기존 installed.json은 읽을 때 정규화하고 다음 저장 때 새 ID를 기록한다. 구 ID가 포함된 원본은 저장 전에 별도 백업한다. 구·신 기록이 충돌하면 차단한다. 구 Backups/delhidden도 조회·검증·복원한다. 설치 폴더·리본·선택 ID는 유지한다.

전체 도구·내 도구·TEST 도구 메뉴를 제거하고 프로그램별 상태/채널 필터로 통합한다. TEST 보기는 동일 카드에서 선택하며 정식 설치는 자동 전환하지 않는다. 색은 정식 설치 녹색, TEST 설치 파랑, 정식 업데이트 주황, TEST 업데이트 보라, 미설치 회색이다. 프로그램 화면의 제작자/조직·도구등록·Reload 중복 진입점은 제거한다. 제작자/조직은 도구등록에서 관리하고 저장/적용은 리본 편집에서 관리한다.

리본의 배치 가능한 버튼 목록은 현재 전체 배치에 있는 ID를 제외한다. 탭/패널/버튼 배치를 삭제하면 목록으로 돌아오며 설치 제거와 다르다. 화면의 독립 문구를 정리했다.

고정 CAD 로더 명령은 ROBIMRUN·ROBIMRELOAD를 제공한다. 기존 DHNET/DELHIDDENNET 및 기능별 Reload·Split 별칭은 제거하며 리본의 명령 ID로 실행한다. 레이어 정리 ID delhidden:cleanup은 유지한다. 과거 기능 DLL을 읽는 FeatureHost 기본값은 이전 기능 호환용이며 신규 런타임은 매니페스트의 타입/어셈블리 이름을 전달한다.

실제 사용자 PC 적용, 실제 호스트 실행, 정식 승격은 각각 별도 확인한다. main 병합과 정식 승격은 이 TEST 작업에 포함하지 않는다.

Manager TEST 5는 TEST 메뉴 제거 후 일반 사용자의 기존 TEST 설치 제거 경로도 프로그램 화면에 유지한다. CAD Loader는 TEST 4를 사용한다.

Manager TEST 6: 정식 설치에 새 TEST가 제공되면 노란색 카드와 별도 TEST 설치 버튼을 표시한다. 정식 업데이트가 동시에 있으면 주황색을 우선하면서 TEST 설치 버튼도 유지한다. 작은 TEST 보기 링크에 의존하지 않는다. TEST 설치에는 기존 확인·권한·검증·리본 보존 절차를 사용한다.
