# Manager 1.0.0-preview.55 TEST

동봉 Revit Host 패키지를 공식 host-v1.0.0-preview.8 배포로 바로잡습니다. preview.54 이하 일부 Manager에서 로컬 체크섬만 확인한 구형 Host preview.1 ZIP을 잘못 동봉하여, 연결 설치/업데이트를 실행해도 실제 최신 리본 지원 Host가 설치되지 않을 수 있었습니다. 이전 배포 파일은 덮어쓰지 않습니다.

공식 Release ZIP SHA-256 e4371baf64aea13bc73d8fa12cb9e47e0088c771ce6e54621e3e387d430d73d8과 내부 DLL ProductVersion 1.0.0-preview.8+43858cde5c6b2b133800a600f58ad36b3da0a2a7을 확인했습니다. release-packages.lock.json을 추가해 공식 배포의 고정 해시가 아닌 구형 Host는 유효한 로컬 sidecar가 있어도 빌드를 차단합니다. CAD v1.0.1은 공식 배포와 이미 일치했습니다.

preview.54의 Native 전용 UI, pyRevit 신규 설치/메뉴 제거와 선택적 잔여 설치 정리, CAD 화면 오류 처리, Git 없는 로그인, 자동/수동 Manager 업데이트 및 프로그램별 리본 편집을 모두 포함합니다. 사용자 도구 선택·리본 배치는 보존하며 기존 pyRevit 파일을 자동으로 삭제하지 않습니다.

Manager 자체 교체와 Revit 연결 교체는 구분합니다. Revit이 실행 중이면 연결 교체를 보류하고, 작업 저장 후 종료한 상태에서 ‘Revit → 리본 편집 → Revit 연결 설치 / 업데이트’를 실행합니다. 재시작 후 실제 리본 적용 확인은 별도 단계입니다.
