# 로그인 대기·Revit 재시작 적용 개선 · 2026-11-04

Manager 1.1.4-test.2는 팀 인증 뒤 전체 도구 저장소 응답을 기다리지 않고 화면을 표시한다. 저장소별 확인은 최대 4개씩 병렬로 처리하고 확인된 도구부터 활성화한다. 시작 시 로컬 설치 검사와 계정 확인도 겹쳐 수행한다. 권한 확인 중·접근 없음·확인 실패를 구분한다.

주기적 갱신은 기존 결과의 원래 3분 만료를 연장하지 않는다. 명시적 접근 거부는 해당 도구를 잠그고 일시적 오류는 아직 유효한 결과만 유지한다. 로그아웃·계정 변경 시 세대 번호를 변경하여 늦은 응답을 폐기한다.

Revit을 재시작한 뒤 과거 PID/시작 시각에 묶인 pending 요청이 남으면, 적용 버튼은 검증된 선택과 파일을 현재 세션용 새 요청 ID로 다시 준비한다. 이전 세션의 완료 기록은 재사용하지 않는다. 검증 중 실행 세션이 바뀌면 재시도를 안내한다. 고정 Host/Loader나 프로토콜은 변경하지 않는다.

검증 기록은 배포 시 갱신한다. 실제 사용자 화면의 소요 시간과 Revit GUI 재시작 적용은 자동 회귀와 별도이며 아직 측정하지 않았다.

리본 미리보기 이름 편집은 포커스를 받지 않는 이름표·빈 영역을 클릭해도 확정한다. 편집 중에만 메시지 필터를 등록하고 입력칸 폐기 시 해제한다. Enter 확정·Escape 취소를 유지한다. 엔진 회귀 296/296 및 기존 카드 UI 263개 통과(클릭 보완 전); 보완 후 UI 검사는 별도로 기록한다.
