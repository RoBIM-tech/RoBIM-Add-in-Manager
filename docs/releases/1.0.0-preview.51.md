# Manager 1.0.0-preview.51 TEST

Git이 없는 PC에서 GitHub 로그인 자체가 실패하던 문제를 RoBIM 조직 소유 OAuth 앱의 HTTPS 기기 인증으로 해결합니다. Git/GCM 설치 없이 로그인·계정 목록·팀 확인·Release 다운로드를 수행하고 Manager 전용 Windows 자격 증명에 저장합니다. 기존 GCM 연결은 한 번 다시 로그인합니다. 인증 만료/철회 시 재로그인하며 비밀번호·토큰을 로그나 설정 JSON에 저장하지 않습니다.

설치 과정에서 .NET 실행 환경을 자동 확인합니다. Manager는 자체 런타임을 포함합니다. Revit 2026.5+/AutoCAD 2026.1.2+의 실제 설치 경로와 요구 x64 런타임을 확인하고, 경로를 찾지 못하면 기능 설치 중 폴더를 지정할 수 있습니다. C:\Revit 2026 같은 별도 경로를 지원합니다. 구형 호스트와 런타임 미설치를 구분하며 .NET 8 호스트 지원은 포함하지 않습니다.

Setup 설치본은 로그인 후 Manager 새 버전을 자동 확인·다운로드·SHA-256 검증합니다. 작업 중이거나 Revit/CAD 실행 중이면 적용을 대기하고 종료 후 Setup으로 교체·재시작합니다. 일반 정식 Manager를 TEST로 자동 전환하지 않습니다. 현재 preview 계열은 후속 preview/정식 승격을 받을 수 있습니다. Portable 덮어쓰기와 도구 선택/기능 자동 업데이트는 수행하지 않습니다. 설치 실패 시 기존 Manager를 다시 열고 동일 파일의 자동 재시도를 중단합니다. 설정에서 Manager 자동 업데이트를 끌 수 있습니다.

Navisworks 메뉴·빈 도구 목록·기본 경로의 설치 버전 표시를 추가합니다. 실제 Navisworks 도구 설치/실행 기능을 구현한 것은 아닙니다.

동봉: 기존 검증 Host 1.0.0-preview.8과 CAD 전체 1.0.1 정식. 기존 고정 Host/Loader 교체는 호스트 종료 후 재시작이 필요합니다. 지정 Revit 5개/CAD 전체 정식은 사용자 gagaggan이 최신 TEST 실사용을 Revit 26.5.0.55/20260731_1210(x64), AutoCAD R25.1.179.0에서 완료했다고 확인한 근거로 별도 배포합니다.

검증: Manager 엔진 255/255(기기 인증 10·설치 환경 6·자동 업데이트 선택 6 포함), 리본 활성화·관리 배치·퇴역 회귀, 실제 PC .NET 설치 환경 확인 통과. Access 연결 14/14는 일반 Windows 사용자 환경에서 통과했습니다. 브라우저 OAuth 승인·새 Manager 자동 교체의 실제 사용자 세션·새 정식 도구의 실제 모델 실행은 별도 확인합니다.
