# Preview 14 · 컴팩트 반응형 카드 · 2026-10-20

- 한 줄 전체를 사용하는 세로 목록을 가로 줄바꿈 그리드로 변경했다. 카드 콘텐츠 폭 약 400 logical pixels를 기준으로 1~3열을 자동 선택한다. 기본/최소 창에서는 2열, 넓은 창에서는 3열로 배치한다. DPI를 반영하며 가로 스크롤이 생기지 않도록 폭과 간격을 계산한다.
- 사용자 추가 요청에 따라 최종 카드 높이 154→88(기존의 약 57%, 중간 132 시안의 2/3), 내부 여백 18→8, 카드 간격 8, 아이콘 58→28 logical pixels. 상단 아이콘/분류/이름과 우상단 설치/제거/더보기 버튼, 가운데 한 줄 설명, 하단 설치 상태를 배치했다. 전체 제목·분류·설명과 적용 안내는 툴팁 또는 기존 더보기에서 확인할 수 있다.
- 창 크기를 변경해도 카드 순서와 검색/정렬/상태 연결을 유지한다. 카드별 ToolTip은 카드 폐기 시 함께 해제하고, 상태가 바뀔 때만 안내 텍스트를 갱신한다. 설치·제거·Reload 처리 서비스는 변경하지 않았다.

검증: 기존 실제 WinForms UI 검사를 확장하여 159/159 통과. 1180/1320/1760/1320 창 너비 변경, DPI별 1/2/3열 경계, 첫 줄 카드 수, 카드 높이, 카드 간 겹침, 가로 스크롤, 최소 창 버튼 영역, 검색/정렬/개별 메뉴를 확인했다. 2열/3열 렌더 이미지를 직접 확인했다. 설치/제거 엔진은 Preview 13의 113개 검증 결과를 유지하며 이번 UI 변경 때문에 다시 실행하지 않았다.

최종 패키지: 임시 경로 설치·재설치·제거 등 10개 검사 통과. 제한된 실행 환경에서 렌더링 타임아웃이 발생했으나 일반 Windows 실행 환경에서 재검사하여 통과했다. 실제 설치 상태 41개 카드를 읽기 전용으로 렌더링하고 우상단 버튼 배치를 확인했다.
