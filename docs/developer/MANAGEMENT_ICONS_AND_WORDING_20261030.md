# 관리 버튼 미리보기·도구 표시 문구 · 2026-10-30

Manager 1.1.1-test.2는 Reload / Add-in Manager 관리 버튼의 미리보기 아이콘을 Manager 안에서 그린다. Revit·CAD 설치 위치, 외부 아이콘 파일, 네트워크나 캐시에 의존하지 않는다. 큰 버튼은 32px, 작은 버튼·2단·3단 묶음은 16px 이미지를 사용한다. 단독 작은 버튼도 실제 선택 크기로 미리보기에 표시한다. 실제 Host/Loader의 아이콘과 바이너리는 교체하지 않는다.

도구의 이름·설명·분류에는 불필요한 구현 분류 문구를 넣지 않는다. 기존 패키지의 설명과 분류는 Manager 표시 단계에서 정리하므로 과거 Release ZIP을 수정하지 않는다. Revit의 독립 뷰처럼 기능 의미가 있는 용어는 보존한다. 설치·module/command ID·Release 채널·사용자 저장 리본 위치/이름은 일괄 치환하지 않는다. 새 관리 버튼의 기본 표시와 새 도구의 기본 분류는 Reload / Add-in Manager, 관리 / 도구를 사용한다.

각 저장소의 현재 README·사용자 문서·개발자 진입점·스킬·자체 검색 설명과 GitHub 소개도 기능 중심으로 정리한다. 새 버튼 생성기는 설명에 분류 접미어를 붙이지 않고 기본 RoBIM/도구 패널을 생성한다. source descriptor의 ID/path/folder/asset/channel은 변경 전후 대조한다. 기존 기능 패키지·고정 로더를 새로 배포할 필요가 없는 메타데이터/문서 변경과 Manager 실행 파일 변경을 구분한다.

검증: Manager 엔진 283개, 실제 WinForms 카드/리본 화면 258개 통과. 화면 검사에는 Revit·CAD 각각 큰/작은/2단/3단 두 관리 버튼의 실제 PictureBox 이미지가 포함된다. Workspace 계약·생성기·문서 및 Python 11개 검사 통과. 실제 PC 설치 및 검증은 최종 전달 기록에서 별도로 보고한다.
