# Preview 23 검증

WinForms UI 196개 검사 통과. 실제 MouseUp/KeyDown/DragDrop/DragEnter 이벤트와 메시지 루프에서 입력창과 호버 타이머를 검사한다. 뒤쪽 절반에 드롭하여 맨 뒤로 이동, 앞쪽 절반에 드롭하여 맨 앞으로 복귀, 타이머에 의한 다른 탭 선택 후 같은 원본을 드롭하는 동작을 포함한다. 묶음 안에서 버튼을 아래로 옮기는 순서 및 용량 보존도 확인한다.

패널 이름 입력창은 편집기 직접 자식이며 화면의 패널 이름과 겹치는 좌표 안에 있는지 확인한다. Escape 취소와 명령 ID 보존을 검사한다. 드래그 비트맵 생성·포인터 오프셋·종료 시 폐기를 확인한다. OLE 드래그 원본은 미리보기를 다시 그려도 폐기되지 않는 UserControl이다. 포인터를 따라가는 창은 활성화·히트 테스트를 받지 않는다.

호스트 연결과 설치된 명령 파일에는 변경이 없어 Revit 종료 및 사용자 모델 실행을 검증에 요구하지 않는다. 설치 패키지 최종 검사·배포 해시는 작업공간 artifacts/manager-preview23-update-result.json에 기록한다. 실제 사람의 마우스 조작 전체를 자동 재현한 검사로 표현하지 않는다.
