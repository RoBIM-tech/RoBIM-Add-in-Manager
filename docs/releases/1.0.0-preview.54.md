# Manager 1.0.0-preview.54 TEST

preview.53 이후 기본 브랜치에 반영된 Native 전용 운영 및 CAD 화면 안정화 변경을 통합합니다. pyRevit 도구·개발·설치 위치 메뉴, 신규 등록·설치·Reload 연결 배포를 종료하고 Native Revit Host/버튼만 사용합니다. 기존 소유 pyRevit 잔여 설치의 백업 후 정리는 별도의 명시적 작업으로 유지하며 업데이트가 자동 삭제하지 않습니다.

AutoCAD 리본 편집의 호환성·선택 오류를 처리하고 화면/비동기 오류를 로컬에 기록합니다. GitHub CLI 없이 검증한 로컬 ZIP/NuGet으로 후보 빌드를 검증하는 스크립트도 포함합니다. 사용자용 Manager의 Git 없는 로그인·설치 시 런타임 확인·자동/수동 Manager 업데이트·프로그램별 리본 편집·Navisworks 빈 목록은 유지합니다.

배포 전 검증에서 제거된 pyRevit 제품을 미리보기가 참조하는 결함을 찾아 Native 예시로 수정했습니다. 업데이트 확인에서도 pyRevit을 포함하지 않습니다. 과거 pyRevit 성공 시나리오는 별도 종료 목록으로 분리하고 통과로 계산하지 않습니다. 기존 잔여 설치 정리와 현재 Native/CAD 경로는 계속 검사합니다.

Host preview.8 / CAD stable1.0.1을 동봉합니다. 사용자 기능 모듈 버전·명령 ID·리본 저장 배치는 변경하지 않습니다. 현재 사용자 PC 설치·고정 Host 교체·실제 Revit 시작 후 리본 적용은 소스/패키지 검증과 구분하여 기록합니다.
