# Preview 32 · 저장소 TEST/정식 직접 설치

2026-10-22. 독립 Revit 카드의 관리 메뉴에서 정식 저장소의 TEST 수정본을 직접 내려받을 수 있다. `저장소 TEST 버전 설치…`와 `저장소 정식 버전 설치…`를 제공한다.

기본 브랜치 패키지 정의의 동일성을 먼저 검사하고, 명시적으로 선택한 릴리스 채널만 다운로드에 적용한다. 기존 ZIP 크기·SHA-256·경로·모듈/명령 ID·배포 메타데이터 검사는 유지한다. 다운로드한 메타데이터가 선택 채널과 다르면 거부한다. 등록 기본 채널과 일반 업데이트 정책은 변경하지 않는다. 기능을 선택하면 기존 설치/리본 보존과 자동 적용 요청 흐름을 사용한다.

## 검증

- 실제 GitHub 시트 저장소에서 정식 0.2.0 → TEST 0.2.1-test.1 → 정식 0.2.0을 다운로드하여 해시/ID/채널을 검증하고, 임시 ManagerPaths에서 선택된 모듈 버전을 확인했다. 등록 파일이 변경되지 않음을 매 단계 바이트 비교했다.
- 실제 Manager UI 검사 222개 통과. 패키지를 아직 받지 않은 중앙 등록 Native 카드에서도 TEST와 정식 설치 메뉴가 표시된다.
- Manager 회귀 172/172, 중앙 등록 및 pyRevit 공용 탭 활성화 회귀 통과.
- 자체 런타임 Manager 빌드와 Setup 생성 성공. 임시 폴더 설치·재설치·렌더·제거·사용자 파일 보존 검사 통과.
- 일반 업데이트는 정식 설치에 TEST를 자동 제안하지 않는다. 명시적 채널 선택과 기본 정식/TEST asset 선택, 지원하지 않는 도구/채널 거부를 회귀 검사한다.
- 사용자 PC의 설치된 Manager 교체, 실제 Revit 모델 변경, 호스트 applied 응답은 이 검사의 범위에 포함하지 않았다.
