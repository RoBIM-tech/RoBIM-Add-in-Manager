# Preview 22 검증

엔진 검사 137개 및 WinForms UI 검사 187개 통과. 구분선 형식·순서 저장, 묶음 내부 및 묶음 중간 구분선 거부, 실제 미리보기 이름 클릭 이벤트와 Enter 확정, 명령 ID 보존, 패널 간 드롭, 탭 추가·선택·이름 변경을 검사했다. 사용자 설치·모델은 UI 검사에서 사용하지 않는다.

실제 Revit 2026.5 Home에서 Native Host 시작을 다시 검사했다. 최신 저널에 Native Host NoError 및 Reload/Manager 등록이 기록되었고 pyRevit 연결에서 관리 탭의 세 연결 버튼을 확인했다. DLL은 등록 경로에 존재하며 패키지·등록을 재검증했다. 앞선 WrongAssembly 오류의 발생 원인은 확정하지 않았으므로 원인 수정으로 단정하지 않는다.

구분선 실제 적용과 설치 패키지 검사, 원래 사용자 배치 복구 결과는 작업공간 artifacts/manager-preview22-update-result.json에 기록한다. 기능 명령을 실행하거나 사용자 모델을 수정하지 않는다. 기존 설치 선택과 준비된 선택의 해시를 검증하며 검증용 리본 배치는 복원한다.
