# 프로그램별 일괄 업데이트

Revit·AutoCAD 도구 화면의 일괄 업데이트는 현재 프로그램의 설치된 도구 중 검증된 업데이트만 처리한다. 검색/표시 필터에 숨겨진 항목도 확인 목록에 포함한다. 로더 교체와 새 도구 설치는 포함하지 않는다. Navisworks는 지원 도구가 없어 비활성화한다.

실행 전 저장소와 설치 상태를 새로 확인하고 대상·현재 버전·제공 버전·채널을 한 번 확인한다. 정식 설치를 선택 사항 TEST로 바꾸지 않으며 TEST 설치에는 권한을 검사한다. TEST의 새 정식 승격은 정식 업데이트로 처리한다. 조회 실패·수정/외부 설치·구형 전환 대상은 제외한다.

확인 후 설치 상태나 내려받은 버전/채널이 달라지면 해당 항목을 적용하지 않는다. 순서대로 기존 단일 도구 설치·검증·배치 보존 경로를 사용한다. 실패한 항목을 기록하고 나머지 도구를 계속하며 이미 성공한 도구를 일괄 롤백하지 않는다. 개별 오류창 대신 마지막에 준비 성공·실패를 함께 표시한다.

Revit은 전체 준비 후 자동 적용을 한 번 요청한다. CAD는 최종 구성 하나를 준비하며 AutoCAD Reload로 적용한다. 준비 성공을 실제 호스트 적용 완료로 표시하지 않는다. 실행 중 중복 도구 변경·다른 일괄 실행은 차단한다.

검증: 순수 계획·권한·채널·변경 대상/설치 상태 차단·부분 실패 검사 5개를 포함해 엔진 261개 통과. UI 235개 통과. 사용자의 실제 도구를 무조건 갱신하는 방식으로 테스트하지 않았다.
