# 도구별 저장소 권한과 별도 로더 · 2026-11-04

Manager 1.1.4-test.1 / Revit Host 1.0.2-test.1 / CAD Loader 1.1.2-test.1 / RoBIM.Access.Core 0.1.1-test.1은 함께 검증하는 TEST 후보입니다. 구현 및 로컬 검사와 GitHub 배포, 사용자 PC 설치, 실제 Revit/AutoCAD 적용은 별도로 기록합니다.

Manager Setup과 Portable에는 Revit Host·CAD Loader ZIP을 포함하지 않습니다. 사용자가 로그인한 뒤 각 로더의 GitHub Release를 조회하고 채널·크기·SHA-256을 검증하여 다운로드합니다. 비공개 로더를 설치하려면 로그인 계정과 조직에 해당 저장소 읽기/콘텐츠 접근 권한이 있어야 합니다. 로더 조회의 HTTP 404와 잘못된 응답은 구분 가능한 메시지로 표시합니다. 기존 설치·개인 파일은 자동 삭제하지 않습니다.

Manager는 등록된 각 모듈 ID와 원본 저장소를 매핑하고 현재 로그인 계정의 저장소 정보·콘텐츠 읽기를 주기적으로 확인합니다. 중복 소유자, 알 수 없는 ID, 접근 불가, 연결 오류 또는 3분이 지난 결과는 차단합니다. 공개 저장소는 모든 사용자가 읽을 수 있으므로 GitHub 읽기 권한만으로 특정 사용자를 제한하지 못합니다. 정식/TEST 팀 권한도 독립적으로 검사합니다. 조회된 권한은 로컬 인증 프로세스에만 유지하고 토큰은 호스트로 보내지 않습니다.

Named Pipe v3는 구형 Host가 이전 채널 전용 v2 권한을 우회해 사용하는 것을 막기 위해 v2와 분리됩니다. 새 Manager 사용 시 두 호스트를 이 TEST 버전 이상으로 업데이트해야 도구를 실행할 수 있습니다. 고정 로더 교체는 해당 Revit/AutoCAD를 모두 종료한 뒤 진행합니다. 리본 배치·선택·설치 파일은 권한 회수 시 삭제하지 않습니다. Revit 명령과 모델리스 작업, CAD 명령 실행 직전에 각각 해당 모듈의 저장소 권한을 다시 확인합니다. 캐시된 화면은 즉시 보안 경계가 아니며 실행은 실시간 IPC로 검사합니다.

검증: Manager 엔진 293개(개별 저장소 회수·복구·충돌·콘텐츠 없는 토큰 포함), 설치본에서 로더 ZIP 부재 및 포터블·네이티브 설치/업그레이드 검사를 수행했습니다. Access v3 파이프의 도구별 허용·타 도구 차단·회수를 검사했습니다. Revit SDK 빌드와 프로토콜·리본·모델리스 회귀, CAD SDK 및 Core Console에서 회수 후 실행 차단·복구를 검사했습니다. 실제 게스트 계정, 실제 Revit/CAD GUI와 사용자의 모델에서 최종 적용은 아직 검증하지 않았습니다.
