# 도구별 권한 관리 정식 승격 · 2026-11-04

사용자의 정식 승격 요청에 따라 RoBIM.Access.Core 0.1.1, Revit Host 1.0.2, CAD Loader 1.1.2, Manager 1.1.4를 순서대로 게시한다. v3 프로토콜의 Manager와 두 고정 로더를 함께 업데이트해야 한다. 이전 v2 Manager와 새 로더를 혼용하면 실행 권한을 받지 못한다.

Manager에는 로그인 대기 단축, 도구별 병렬 권한 확인, Revit 재시작 후 요청 재준비, 리본 이름 편집 외부 클릭 확정을 포함한다. 로더 기능 구현은 검증한 TEST와 동일하며 정식 Access 버전을 고정한다. 기존 TEST Release와 사용자 선택·리본·ID를 보존한다.

검증: 기존 TEST 실제 PC에서 Revit 13개 모듈/CAD 4개 작업의 applied 기록과 Manager v3 통신 허용/미등록 차단을 확인했다. 실제 게스트 계정 로그인·권한 회수/복구·사용자 모델 명령 검증은 미수행이다. 정식 빌드·게시와 정식 실제 PC 설치 결과는 각각 구분해 기록한다. 실사용 승격이 새 모델 기능 검증을 뜻하지 않는다.
