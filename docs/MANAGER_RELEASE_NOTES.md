- 준비 단계에서 설치 파일과 실행 중인 기능을 바꾸지 않음. CAD 적용 응답을 받아 준비됨/완료/실패 표시.
- 추가 작업에서 최신 CAD 기능 다운로드 또는 ZIP/SHA-256으로 기능 준비. 고정 코어가 바뀌면 재시작 후 전체 업데이트 안내.
- 새 CAD catalog의 모듈/버튼/경로를 검증하고 기존 단일 DLL 설치 형식과 호환 유지.
- 기존 Revit 설치·Reload, GitHub 인증·백업과 일반 설치 보호 유지.

검증: Manager 엔진 69개, CAD 통합 18개, Portable 설치 검증 8개, 별도 Test AppId의 네이티브 Setup 7항목 통과. Manager 실제 준비 코드 → Core Console Reload → 선택 실행/미선택 차단 → 응답까지 연동 확인. 버튼 선택 창 렌더링을 확인했습니다. 실제 AutoCAD GUI의 리본 클릭·작업공간 변경·연속 창 조작은 현장 확인 대상입니다.

이 작업본의 설치 파일은 artifacts/RoBIM-Manager-Setup.exe입니다. Manager 자체와 CAD 연결 모듈을 이번 버전으로 바꾸려면 해당 프로그램을 종료해야 합니다. 기존 사용자 설치본에 자동 설치하거나 GitHub에 배포하지 않았습니다.

**이전 Preview 5 기록**

매니저를 RoBIM-tech/RoBIM-Add-in-Manager 저장소로 분리했습니다. RoBIM-CAD는 CAD 도구 소스와 CAD 패키지만 관리합니다.

- Revit / AutoCAD 화면을 분리하고 해당 제품 도구만 표시
- 도구 선택 후 기본 작업 버튼 하나로 설치·업데이트 안내
- 제품 종료 여부에 따라 버튼과 다음 단계가 자동 변경
- 새 CAD 설치는 로그인 없이 동봉 패키지 사용 가능
- Revit 기존 설치는 실행 중 업데이트 준비 후 Revit 내부 적용
- 첫 Reload 준비 시 연결 확장이 없으면 자동 설치
- 일반 설치 후 해당 도구의 오래된 Reload 준비 요청 정리
- Git URL 등록은 도구 추가, 인증과 토큰은 설정 / GitHub로 이동
- 창·바로가기·Windows 앱 이름을 RoBIM Add-in Manager로 정리. 기존 설치 경로와 설정·인증·백업은 유지

설치 파일을 실행하기 전에 기존 매니저를 종료하십시오. 매니저 설치 후 Revit 또는 AutoCAD에서 도구를 선택하고 설치 버튼을 누르면 됩니다. CAD DLL과 새 Revit/일반 확장 설치는 제품 종료가 필요합니다.

설치 엔진·온라인 연동 검증과 Setup 검증 결과는 docs/MANAGER_VALIDATION.md를 참고하십시오. 실제 Revit 모델 내 Reload와 신규 유효 PAT 입력은 사용자 환경 확인 범위입니다.
