# Preview 21 검증

설치 위치: 위치 변경, 기존 백업 복원, 대상 충돌·로컬 수정 보호, INI의 다른 경로와 BOM 보존, 등록 실패 복구, 호스트 재확인, 준비된 선택 원본 경로 갱신을 임시 폴더에서 검사한다. 실제 사용자 설치 경로는 사용자가 선택하기 전까지 변경하지 않는다. 연결 모듈은 기본 확장 폴더에 두고 선택 설치 및 개발 프로필에 사용자 지정 경로를 적용한다.

리본: Revit 2026.5 Home에서 실제 등록한 세 명령의 배치를 검사했다. 2단은 RibbonRowPanel 안에 버튼 2개와 RowBreak 1개, 3단은 버튼 3개와 RowBreak 2개가 생성되었다. 동일 세션의 UI 재적용과 실제 리본 캡처를 확인했다. 기능 명령과 사용자 모델은 실행하지 않았다. 검증용 설치와 배치는 원래 상태로 복원하며 기존 준비된 선택 및 독립 시트 모듈 선택은 보존한다.

Reload: 실제 BeamToSlab 캐시를 복제한 격리 설치에서 개발용 프로젝트 제외, 실행 helper 보존, 설치·제거를 확인했다. 준비된 선택의 종료 후 적용 및 실패 시 보존은 회귀 검사에 포함한다.

최종 검사 수와 설치된 파일 해시는 작업공간의 manager-preview21-update-result.json에 기록한다. 네트워크 제한으로 NuGet 취약성 데이터 조회 경고가 있었으며, 취약성 조회 성공을 검증 결과에 포함하지 않는다.
