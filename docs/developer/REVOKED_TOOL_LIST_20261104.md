# 권한 없는 도구 목록과 제거 · 2026-11-04

권한이 없는 미설치 도구는 과거 검색/등록/화면 캐시가 있어도 프로그램 도구 목록에 표시하지 않는다. 설치된 도구는 카드와 제거 기본 버튼만 제공하며 TEST 설치와 추가 작업은 차단한다. 제거가 호스트에 적용되기 전에는 대기 카드를 유지하고 적용 완료 뒤에는 숨긴다. 캐시 자체를 삭제하는 대신 공통 권한 기준으로 표시하므로 권한 복구 후 정상 노출된다.

사용자 요청에 따라 Revit 버튼은 기존 비활성화 방식을 유지한다. 고정 로더와 공용 권한 프로토콜은 변경하지 않는다. Manager 1.1.5-test.1이며 정식 승격은 별도다. 로컬 변경/외부 설치 보호 및 채널 권한은 제거 경로의 기존 검증을 유지한다.

검증 결과는 배포 시 기록한다. 실제 게스트 계정의 회수/복구 검증은 자동 검사와 별도다.
