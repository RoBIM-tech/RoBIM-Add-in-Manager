# Manager 1.0.0-preview.53 TEST

실제 PC 진단에서 정식 Revit 도구 5개는 적용됐지만 독립 Host는 preview.1로 남아 있었고, 저장된 3개 탭 대신 패키지 기본 탭들이 표시됐습니다. 현재 세션의 Native 버튼 적용 응답과 이전 세션의 UI 적용 응답은 서로 다른 기록입니다. TEST→정식 전환 때 사용자 리본 ID/저장 배치가 사라진 문제는 아니었습니다.

리본 편집에 ‘Revit 연결 설치 / 업데이트’를 추가합니다. Revit 종료 후 기존 InstallHost의 SHA-256·소유권·백업·등록 보존 검증으로 동봉 Host preview.8을 설치합니다. 독립 모드에서 Revit 적용 시 연결 패키지의 실제 해시를 비교하고, 오래된 연결로 Revit 실행 중이면 정확한 복구 방법을 안내하며 완료라고 표시하지 않습니다. Revit이 닫혔으면 연결을 먼저 설치하고 저장된 배치를 다음 시작에 적용합니다.

도구 ID·선택·사용자 리본·NativeProtocol 계약과 Host 바이너리는 변경하지 않습니다. Manager preview.52와 같은 Host preview.8/CAD stable1.0.1을 동봉합니다. 새 Host 구현이 필요한 결함으로 판단하여 임의로 DLL을 교체하지 않습니다.

검증: 임시 경로에서 구형/현재/누락/손상된 연결 판별, 실행 중 교체 차단, 종료 후 교체 및 저장 리본 보존을 검사합니다. 실제 PC는 Revit 실행 중이므로 연결 교체와 다음 실행 리본 적용은 미수행입니다. 현재 모델을 닫거나 변경하지 않았습니다.
